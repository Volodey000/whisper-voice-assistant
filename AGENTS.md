## 5. Контекст проекта Whisper Voice Assistant

### Стек технологий
- **Язык и версия:** Python 3.10 – 3.12 (основная сборка 3.11.7 x64 Windows).
- **GUI:** PyQt6 (светлая нейтральная тема Zinc Light, кастомные плоские виджеты, Bezier-сплайны волны).
- **STT Движок:** Faster-Whisper (библиотека CTranslate2) с локальными весами моделей в `models/`.
- **Нейросети:** PyTorch (CUDA 12.1 для NVIDIA GPU с float16, либо CPU с целочисленным квантованием int8).
- **Аудио:** `sounddevice`, `numpy`, `scipy`, `silero-vad` (детектор активности речи).
- **Системная интеграция Windows:** Win32 API (`RegisterHotKey`, `SendInput`), буфер обмена Windows, системный трей, VBS/BAT сценарии автозапуска.

### Команды
- **Запуск приложения:**
  ```cmd
  start_whisper.bat
  ```
  или напрямую через виртуальное окружение:
  ```powershell
  .\.venv\Scripts\python.exe main.py
  ```
- **Тихий запуск в трей:** `wscript run_silent.vbs`
- **Запуск тестов устойчивости:**
  ```powershell
  .\.venv\Scripts\python.exe test_resilience.py
  ```
- **Проверка окружения и зависимостей:**
  ```powershell
  .\.venv\Scripts\python.exe check_environment.py
  ```

### Структура проекта
- `contracts.py`: Единый контрактный слой (DTO, интерфейсы, типизация DTO, схемы config/history).
- `main.py`: Точка входа, жизненный цикл Qt приложения, системный трей и координация горячих клавиш.
- `gui.py`: Главное окно программы (вкладки: Диктовка, Транскрибация файлов, История, Словарь, Настройки).
- `overlay.py`: Плавающий индикатор записи с живой звуковой волной на сплайнах Безье и кнопкой мгновенной отмены `✕`.
- `transcriber.py`: Класс `WhisperEngine` — загрузка локальных/скачиваемых моделей, VAD, GPU/CPU отказоустойчивость.
- `audio_recorder.py`: Запись с микрофона, шумоподавление (Noise Gate), 11-полосный FFT анализ частот.
- `hotkey_manager.py`: Глобальные горячие клавиши через Win32 `RegisterHotKey` (наивысший приоритет над полноэкранными окнами) + fallback на `pynput`.
- `config.py` / `config.json`: Настройки с атомарной записью (`.tmp` + `os.replace`) и автовосстановлением поврежденных JSON.
- `history_manager.py` / `history.json`: Журнал расшифровок с атомарным сохранением.
- `vocabulary.py`: Словарь горячих терминов (hotwords prompt) и таблица быстрых автозамен.
- `text_cleaner.py`: Очистка распознанного текста от междометий, вокальных пауз и заиканий (RU и EN).
- `paste_helper.py`: Надежная эмуляция вставки `Ctrl + V` в активное окно через Win32 `SendInput` с каскадом буфера.
- `hardware.py`: Автоопределение видеокарты NVIDIA, объема VRAM и количества ядер CPU для выбора модели.
- `cuda_setup.py`: Настройка путей DLL PyTorch и CUDA для корректной работы CTranslate2.
- `models/`: Локальные модели Faster-Whisper (`large-v3-turbo`, `small`, и др.) для 100% автономной работы без интернета.

### Запрещено (Forbidden)
1. **Запрещено модифицировать или удалять файлы весов в `models/` вручную.** Приложение работает в автономном режиме без интернета, опираясь на эти файлы.
2. **Запрещено ломать обратную совместимость `DEFAULT_CONFIG` в `config.py`.** Любые новые параметры конфигурации обязаны иметь дефолтное значение, чтобы старые `config.json` пользователей не приводили к сбою.
3. **Запрещено передавать `compute_type="float16"` для CPU.** Библиотека CTranslate2 гарантированно падает с ошибкой на CPU при float16. Для CPU используется строго `int8` или `float32`.
4. **Запрещено выполнять блокирующие вызовы в GUI-потоке PyQt.** Вся тяжелая обработка аудио и транскрибация обязана исполняться в фоновых потоках `QThread` (`workers.py`).
5. **Запрещена прямая запись в `config.json` и `history.json` без временного файла.** Всегда используйте безопасный паттерн: запись в `.tmp` -> `os.replace`.

## 6. Project Learnings (Накопленные инженерные правила)

- **CTranslate2 & CUDA DLL на Windows:** PyTorch 2.5+ хранит CUDA DLL внутри `site-packages\torch\lib`. Модуль `cuda_setup.py` обязан вызываться до первого импорта `faster_whisper`, регистрируя эту директорию через `os.add_dll_directory`.
- **Приоритет горячих клавиш в Windows:** Обычные хуки (`pynput` / `keyboard`) блокируются или пропускают нажатия в играх, терминалах от имени администратора и окнах с повышенными привилегиями. В `hotkey_manager.py` реализован системный Win32 `RegisterHotKey`, имеющий наивысший приоритет ядра ОС.
- **Двухпроходное распознавание речи:** Если Silero VAD отсек короткую или шепотную фразу как тишину, `WhisperEngine` автоматически выполняет повторный проход без VAD, предотвращая потерю реплики.
- **Шумоподавление (Noise Gate):** По умолчанию выключено (`noise_gate: False`), чтобы не обрезать начало тихих слов и окончания фраз при качественном микрофоне.
- **Синхронизация буфера обмена:** При авто-вставке (`Ctrl+V`) выдерживается небольшая системная пауза (40–80 мс) перед эмуляцией клавиш, чтобы целевое приложение успело зафиксировать обновленный текст в буфере Windows.
- **Приоритет системного MSVC runtime (0xc0000005 fix):** `cuda_setup.py` обязан импортироваться на самой первой строке `main.py` и `check_environment.py`, чтобы загрузить современный `msvcp140.dll` (14.5x) из `System32` до того, как PyQt6 загрузит свой устаревший v14.26 из `PyQt6\Qt6\bin`, приводящий к сбою при транскрибации.
